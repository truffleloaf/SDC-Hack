# Domain 1 requirements

This matrix connects each Future-Ready Workforce requirement to visible evidence, implementation code, automated checks and a stated limitation.

| Requirement | App evidence | Code | Automated evidence | Limit |
|---|---|---|---|---|
| Skills intake | `/start`, `/skills` | [`components/start/`](../pivott-web-application-design/components/start/), [`lib/resume/`](../pivott-web-application-design/lib/resume/) | [`resume.test.ts`](../pivott-web-application-design/lib/resume/resume.test.ts), [`personal-tool.test.ts`](../pivott-web-application-design/lib/personal-tool.test.ts) | Résumé matching is local phrase matching. It is not an LLM assessment or ATS score. |
| AI trend signal layer | `/signals` | [`lib/catalog.ts`](../pivott-web-application-design/lib/catalog.ts), [`backend/app/live/trends.py`](../backend/app/live/trends.py) | [`trends.test.ts`](../pivott-web-application-design/lib/trends.test.ts), [`test_trends.py`](../backend/tests/test_trends.py) | Thin or missing history produces an explicit insufficient-data state instead of a trend claim. |
| Future-role matching | `/routes` | [`lib/engine.ts`](../pivott-web-application-design/lib/engine.ts), [`backend/app/engine.py`](../backend/app/engine.py) | [`engine.test.ts`](../pivott-web-application-design/lib/engine.test.ts), [`test_engine.py`](../backend/tests/test_engine.py) | Fit is an explainable estimate based on selected tasks and rated skills; it is not a hiring decision. |
| Reskilling pathway | `/pathway` | [`components/pathway/`](../pivott-web-application-design/components/pathway/), [`backend/app/services/pathway.py`](../backend/app/services/pathway.py) | [`resources.test.ts`](../pivott-web-application-design/lib/resources.test.ts), [`test_api.py`](../backend/tests/test_api.py) | Hours are planning estimates. The app identifies when a suitable verified resource is unavailable. |
| SDG mapping | `/routes`, `/pathway`, `/passport` | [`backend sdg-map.json`](../backend/app/data/sdg-map.json), [`frontend sdg-map.json`](../pivott-web-application-design/lib/data/sdg-map.json) | [`sdg.test.ts`](../pivott-web-application-design/lib/sdg.test.ts), [`test_sdg.py`](../backend/tests/test_sdg.py) | Mappings cover all 17 goals but remain team judgement, not an official UN classification or measured impact. |
| Handling uncertainty | `/map`, `/routes`, `/method` | [`lib/engine.ts`](../pivott-web-application-design/lib/engine.ts), [`lib/preview.ts`](../pivott-web-application-design/lib/preview.ts) | [`scenarios.test.ts`](../pivott-web-application-design/lib/scenarios.test.ts), [`fairness.test.ts`](../pivott-web-application-design/lib/fairness.test.ts) | Slow, Normal and Fast make assumptions visible; none is a forecast or probability of job loss. |

The implementation uses synthetic demo profiles and attributed public data. It stores no real CV in the demo, does not invent job listings, courses or statistics, cites sources for recommendations where a source exists, and leaves career decisions with the person using the tool. The detailed validation history is in [verification.md](verification.md).
