# P1-4: Pathways and resources

This archived work package connected skill gaps to ordered learning steps.

## Scope

- Prioritize gaps by required level, importance, and role demand.
- Select attributed resources for each gap.
- Recalculate weeks from total hours and weekly availability.
- Support free-only filtering, step completion, and calendar export.

## Acceptance

The same input produces the same pathway, missing resources are shown honestly, free-only never selects a paid resource, and completion changes only after explicit confirmation.
