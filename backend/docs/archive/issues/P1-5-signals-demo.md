# P1-5: Signals and demo controls

This archived work package made signal changes visible and reversible during a demonstration.

## Scope

- Validate dated signal evidence and affected tasks.
- Recompute analysis with selected user signals.
- Return before/after differences without mutating unrelated tasks.
- Restrict seed reset to explicitly enabled demo environments.

## Acceptance

Invalid dates, URLs, strengths, and task IDs fail validation. Recomputing changes only impacted tasks, and live datasets cannot use demo reset controls.
